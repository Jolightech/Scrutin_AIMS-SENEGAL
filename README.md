# Scrutin_AIMS-SENEGAL
An online voting platform designed to facilitate the election of student focal points. It provides a simple, transparent, and accessible way for eligible voters to cast their votes and participate in the selection of their representatives.

- Live site: https://jolightech.github.io/Scrutin_AIMS-SENEGAL/
- Voting link: https://jolightech.github.io/Scrutin_AIMS-SENEGAL/#email
- Static site (GitHub Pages) + Firebase Firestore, confirmed `@aims-senegal.org` addresses only.
- Full documentation (French): [LISEZ-MOI.md](LISEZ-MOI.md)
